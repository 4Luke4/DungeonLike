# Pinned dependencies for the repository validation scripts in this directory.
#
# Only `validate_labels.py` needs a third-party package; the other scripts use
# the standard library only.
#
# Hash-pinned deliberately. These scripts decide whether a change is allowed to
# merge, so a compromised or yanked release must not be able to silently alter
# what CI enforces. `--require-hashes` makes pip refuse anything that does not
# match one of the digests below.
#
# Both the CPython 3.13 manylinux x86_64 wheel and the source distribution are
# listed, so the install succeeds whether or not the runner can use the wheel.
#
# To update: bump the version, then take the new digests from
# https://pypi.org/pypi/PyYAML/json
